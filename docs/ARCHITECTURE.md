## 🧩 רכיבים עיקריים

### 1. מסמכי מאגר

**תפקיד:** להכיל את הנתונים והמבנה של דמויות התנ״ך.

**פורמט:** Markdown עם דוגמאות JSON.

**מבנה:**
- תיאור כללי
- מבנה JSON לדוגמה
- קטגוריות וארגון
- הנחיות שימוש

### 2. מבנה נתונים

**פורמט:** JSON

**מבנה בסיסי:**
```json
{
  "name": "string",
  "english_name": "string",
  "nickname": "string",
  "tribe": "string",
  "era": "string",
  "symbol": "string",
  "energy_color": "string",
  "core_element": "string",
  "mission": "string",
  "strengths": ["string"],
  "weaknesses": ["string"],
  "spiritual_level": "string",
  "sefira": "string",
  "archetype": "string",
  "quote": "string",
  "lesson": "string"
}
```

### 3. תיעוד

**מבנה:** Markdown files ב-`docs/`

**תוכן:**
- מדריכים
- API (עתידי)
- סגנון
- פריסה

### 4. אוטומציה

**מיקום:** `.github/workflows/`

**תפקידים:**
- CI/CD
- בדיקות
- שחרורים
- אבטחה

## 📚 תיעוד

### מבנה

1. **כותרת** — מה זה
2. **תיאור** — למה זה
3. **דוגמאות** — איך להשתמש
4. **קישורים** — קישורים רלוונטיים

### טון

- **ידידותי** אבל מקצועי

## 📝 Commit Messages

### פורמט

```
סוג: תיאור קצר

תיאור מפורט (אם נדרש)
```

### סוגים

- `feat:` — תכונה חדשה
- `fix:` — תיקון באג
- `docs:` — שינוי תיעוד
- `style:` — שינוי עיצוב
- `refactor:` — refactoring
- `test:` — בדיקות
- `chore:` — תחזוקה

### דוגמאות

```
feat: הוספת דמות חדשה - אברהם אבינו

docs: שיפור תיעוד במדריך התחלה

fix: תיקון שגיאת כתיב בשם דמות
```
